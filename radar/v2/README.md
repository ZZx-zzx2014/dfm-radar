# 雷达前端 v2 · 手写实现

## 特点

- **无构建、无压缩**：直接以原生 ES Module 运行，浏览器原生支持
- **模块化**：配置 / 服务 / UI 分层，单一职责
- **依赖注入**：`main.js` 负责装配，模块间通过参数传递依赖，便于替换与测试
- **可读可审计**：全部为手写源码，任何人可直接阅读与审查

## 目录

```
v2/
├── index.html                 页面骨架
└── app/
    ├── main.js                入口：装配与启动
    ├── config.js              常量配置（无魔法值）
    ├── store.js               本地状态与持久化
    ├── dom.js                 DOM 工具
    ├── services/              业务服务（无 UI 依赖）
    │   ├── keys.js            卡密校验
    │   ├── relay.js           中继 WS 客户端（重连/心跳/事件）
    │   └── chat.js            房间聊天
    ├── ui/                    视图层（无网络逻辑）
    │   ├── gate.js            卡密验证门
    │   ├── entry.js           加入房间页
    │   └── hud.js             状态栏与房间徽标
    └── styles/
        ├── tokens.css         设计令牌
        └── app.css            组件样式
```

## 架构约定

| 层 | 允许依赖 | 禁止 |
|---|---|---|
| `services/*` | `config` `store` | DOM、UI |
| `ui/*` | `dom` `services` `store` | 直接 fetch/WebSocket |
| `main.js` | 全部 | 业务细节 |

## 与旧版的关系

旧版（`assets/app.js` 等）是构建产物，地图与 3D 模型仍由其提供。
v2 重写了**入口页 · 卡密门 · 连接层 · 状态层**，这些是此前补丁最密集、最易出错的部分。
后续可继续以同样方式替换其余功能，最终完全摆脱构建产物。
