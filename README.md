# DFM · 玩家价值面板

网页版雷达看板：输入 4 位房间号查看地图、玩家价值榜、带价物资榜；支持按节点区间自动扫描 1000~5999 并按价值排序。

## 房间号 → 节点

实测规则：**节点号 = 房间号 ÷ 1000 取整**

| 节点 | 房间号区间 |
|---|---|
| 1 号 | 1000 – 1999 |
| 2 号 | 2000 – 2999 |
| 3 号 | 3000 – 3999 |
| 4 号 | 4000 – 4999 |
| 5 号 | 5000 – 5999 |

## 连接方式（页面上可选）

雷达节点只提供 **ws://**（无 TLS）。浏览器对 **https 页面**有两条硬限制：

1. 禁止 https 页面连接 `ws://`（混合内容拦截）
2. 禁止公网页面访问 `127.0.0.1`（Local Network Access）

因此：

| 页面打开方式 | 可用连接方式 |
|---|---|
| `file://`（本地双击） | **直连节点** ✅ |
| `http://`（本地 http 服务） | **直连节点** ✅ |
| `https://`（GitHub Pages / 微信内打开） | 仅 **公网 wss 中继** ✅ |

### 部署公网 wss 中继（让 https 页面也能用）

在雷达节点所在服务器上以 root 运行：

```bash
bash deploy_wss.sh ws.你的域名.com
```

脚本会：把 TCP 中继装到 `/opt/radar/relay.py`（监听 127.0.0.1:8899）、注册 systemd 服务、新增独立 nginx 站点（不覆盖已有配置）、用 certbot 申请证书。

前置条件：该域名的 A 记录已指向本机公网 IP，且 80/443 可从公网访问。

完成后网页上选「公网 wss 中继」，填 `wss://ws.你的域名.com/ws?room=`。

### 本地中继（同机调试用）

```bash
python3 radar_proxy.py          # 默认 127.0.0.1:8898
```

注意：本地中继只能被 `file://` / 本地 `http://` 页面使用；**https 页面访问 127.0.0.1 会被浏览器拦截**。

## 说明

- 「玩家价值」是按坐标邻近把带价物资归给最近玩家后的**推断值**，非客户端上报的真实归属。
- 仅部分物资带 `price`，总价值是**已知价格之和**。
- 扫描会对服务端发起大量连接（全段约 5000 次），请适量使用。
