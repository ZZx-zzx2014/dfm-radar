# DFM · 玩家价值面板

网页版雷达看板：输入 4 位房间号即可查看该房间的地图、玩家价值榜与带价物资榜；支持按节点区间自动扫描 1000~5999 全部房间并按价值排序。

## 房间号 → 节点

实测规则：**节点号 = 房间号 ÷ 1000 取整**

| 节点 | 房间号区间 |
|---|---|
| 1 号 | 1000 – 1999 |
| 2 号 | 2000 – 2999 |
| 3 号 | 3000 – 3999 |
| 4 号 | 4000 – 4999 |
| 5 号 | 5000 – 5999 |

## 重要：浏览器「混合内容」限制

雷达节点只提供 **ws://**（无 TLS）。浏览器禁止 **https 页面**连接 `ws://`，所以本页从 GitHub Pages（https）打开时，**必须**配合本地中继使用。

中继监听 `ws://127.0.0.1:8898` —— 回环地址豁免混合内容限制。

```bash
python3 radar_proxy.py     # 启动本地中继（只绑 127.0.0.1）
```

然后网页上勾选「本地代理」。注意：`127.0.0.1` 指向**打开网页的那台设备**，所以中继要跑在同一台机器上；在手机上打开则无效。

## 说明

- 「玩家价值」是按坐标邻近把带价物资归给最近玩家后的推断值，非客户端上报的真实归属。
- 仅部分物资带 `price`，总价值是已知价格之和。
